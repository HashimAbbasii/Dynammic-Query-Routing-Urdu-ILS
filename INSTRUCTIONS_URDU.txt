STEP 1 — Zip Extract Karo
═══════════════════════════════════════════════════════════════

2. Right-click karo → "Extract All..." → koi bhi temporary folder
   choose karo (e.g. Desktop pe "ULTRA_fix_package" naam se).

STEP 4 — VS Code Mein Check Karo
═══════════════════════════════════════════════════════════════
1. VS Code kholo, apna ULTRA_Project folder open karo
   (File > Open Folder).
2. Left sidebar mein "Source Control" icon pe click karo
   (teeno lines wala icon, ya Ctrl+Shift+G).
3. Yahan aapko "Changes" ke neeche saari modified files dikhengi
   (README.md, data/training_queries_real.py, wagera) — ye normal
   hai, isi ka matlab hai ke copy-paste sahi hua.
4. Confirm karo ke branch "validation-response" hi selected hai
   (bottom-left corner mein branch ka naam dikhta hai VS Code mein).
   Agar "main" ya kuch aur likha hai, click karke
   "validation-response" select karo.

═══════════════════════════════════════════════════════════════
STEP 5 — Commit Karo
═══════════════════════════════════════════════════════════════
1. Source Control panel ke upar ek text box hai
   ("Message" likha hoga) — usmein ye likho:

   Fix: root-cause Roman Urdu external validation weakness (74% to 100%)

2. Us text box ke upar "✓" (checkmark) icon pe click karo — ye
   "Commit" button hai. (Agar email/name maange to apna naam aur
   koi bhi email likh do, jaisa pehle diya tha.)

═══════════════════════════════════════════════════════════════
STEP 6 — Push Karo GitHub Par
═══════════════════════════════════════════════════════════════
1. Commit hone ke baad, Source Control panel mein "Sync Changes"
   ya "Push" likha button dikhega — usi pe click karo.
2. Agar GitHub login maange to apna GitHub account se sign-in
   karo (browser khulega, allow karo).
3. Push complete hone ke baad, GitHub website par jaake
   "validation-response" branch check karo — README.md mein
   naye "100%" wale numbers dikhne chahiye.

═══════════════════════════════════════════════════════════════
STEP 7 (BAAD MEIN) — main Branch Mein Merge
═══════════════════════════════════════════════════════════════
Jab aap khud ek baar GitHub par jaake "validation-response" branch
ka README.md aur robustness_report.csv check kar lo aur satisfied
ho jao — tab GitHub website par "Compare & pull request" button
use karke isko "main" branch mein merge kar sakte ho. Ye step
abhi mat karo — pehle khud ek baar verify kar lo, phir agli chat
mein bata dena, main saath check kar dunga.
