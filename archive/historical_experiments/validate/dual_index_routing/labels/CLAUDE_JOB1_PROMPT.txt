JOB 1 — LABEL 40 QUERIES SHORT or LONG

You are labeling Urdu / Roman Urdu news-search queries.

Rule:
SHORT or LONG is NOT "is the sentence short or long?"
It is: which library ROOM would help the user more?

SHORT = headlines only are enough. The user wants ONE fact (price, score, date, who won, temperature). A good headline could answer it.
LONG  = they need the full article. The user wants why / how / damage / effects / comparison / review. A headline like "team lost" is not enough.

Do NOT count words. Do NOT use 150 characters. Do NOT use the 6-word rule.
If a 3-word query asks WHY, it is LONG.
If a 7-word query asks today's temperature, it is SHORT.
If unsure, write UNSURE and a one-line reason.

Output ONLY 40 lines in this exact format. No extra commentary:
H001	LONG
H002	LONG
...
